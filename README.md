## 📌 Project Overview
This project presents a production-grade Machine Learning pipeline focused on predicting vehicle CO2 emissions using advanced Regression Modeling techniques.

The analysis combines data preprocessing, feature engineering, exploratory data analysis, statistical validation, and predictive modeling to identify the major factors influencing vehicle emissions and fuel consumption patterns.

The project simulates a real-world automotive analytics use case aimed at enabling data-driven environmental and sustainability insights.

---

## 🎯 Business Objectives

- Predict vehicle CO2 emissions with Regression Modeling
- Analyze relationships between engine specifications and emissions
- Identify key emission-driving vehicle characteristics
- Perform feature engineering for improved model performance
- Build scalable and interpretable predictive analytics workflows
- Evaluate model accuracy using statistical performance metrics

## 🗂 Dataset Summary

The dataset contains detailed vehicle specifications and fuel consumption metrics.

### Key Features:

| Feature | Description |
|---|---|
| Make | Vehicle manufacturer |
| Model | Vehicle model |
| Vehicle Class | Type/category of vehicle |
| Engine Size (L) | Engine displacement |
| Cylinders | Number of engine cylinders |
| Transmission | Transmission type |
| Fuel Type | Fuel category |
| Fuel Consumption City | City fuel efficiency |
| Fuel Consumption Hwy | Highway fuel efficiency |
| Fuel Consumption Comb | Combined fuel efficiency |
| CO2 Emissions | Target variable |

## 🔍 End-to-End Analytical Workflow

### 1️⃣ Data Preprocessing & Feature Engineering
- Data cleaning & validation
- Missing value analysis
- Feature selection
- Encoding categorical variables
- Feature engineering
- Data scaling & normalization
- Train-test split implementation

### 2️⃣ Exploratory Data Analysis (EDA)
- Emission distribution analysis
- Fuel consumption trend analysis
- Correlation heatmaps
- Engine size vs emission analysis
- Vehicle class contribution analysis
- Statistical pattern identification

### 3️⃣ Regression Modeling
- Linear Regression model development
- Model training & evaluation
- Prediction analysis
- Residual analysis
- Model interpretability assessment

### 4️⃣ Performance Evaluation
- Mean Absolute Error (MAE)

## 📈 Key Insights

- Vehicles with higher cylinder counts generally produce greater emissions
- Combined fuel consumption is highly correlated with emission output
